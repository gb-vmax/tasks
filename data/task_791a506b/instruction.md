As a container specialist managing microservices, you need to set an environment variable named MICROSERVICE_ENV with the value staging for the current terminal session. After you have set the variable, verify the configuration by outputting its value and writing it to a log file at /home/user/config_logs/env_setting.log. The log file must contain exactly one line with the format: 

MICROSERVICE_ENV=staging

No extra whitespace or output is allowed in the log file; it should contain only this exact line.
