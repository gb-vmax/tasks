# Bug Report

### Describe the bug

The autogenerated sidebar is not working correctly with document IDs. When using docs with paths containing slashes, the sidebar generation seems to be using the wrong part of the document ID.

### Reproduction

```
docs/
  guide/
    getting-started.md
    advanced/
      configuration.md
```

With document IDs like:
- `guide/getting-started`
- `guide/advanced/configuration`

The sidebar generator is not extracting the correct local document ID from the full path. Instead of getting the last segment after the final slash (e.g., `getting-started`, `configuration`), it appears to be extracting something else entirely.

### Expected behavior

The `getLocalDocId` function should return the last segment of the document path:
- `guide/getting-started` → should return `getting-started`
- `guide/advanced/configuration` → should return `configuration`

This is needed for proper sidebar item generation and linking.

### System Info
- Docusaurus version: latest
- Node version: 18.x
