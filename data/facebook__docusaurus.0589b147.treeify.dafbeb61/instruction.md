# Bug Report

### Describe the bug

I'm experiencing an issue with autogenerated sidebars where the folder structure isn't being recognized correctly on Windows systems. The sidebar generation seems to be breaking the directory hierarchy, causing docs to not be properly nested under their parent categories.

### Reproduction

Given a docs structure like:
```
docs/
  guide/
    intro.md
    advanced/
      config.md
```

When using autogenerated sidebars, the `config.md` file doesn't appear under the `advanced` category as expected. Instead, the sidebar structure appears flattened or malformed.

This seems to only happen on Windows - the same setup works fine on macOS and Linux.

### Expected behavior

The autogenerated sidebar should properly reflect the nested folder structure:
- Guide
  - intro.md
  - Advanced
    - config.md

### System Info
- Docusaurus version: latest
- OS: Windows 10
- Node version: 18.x

Has anyone else run into this? It's making it difficult to organize documentation with nested categories on Windows environments.
