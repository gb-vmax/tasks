# Bug Report

### Describe the bug

When using autogenerated sidebars with nested documentation directories, the sidebar structure is not being generated correctly. Documents appear to be placed at the wrong level in the sidebar hierarchy, causing the nested folder structure to be lost or misrepresented.

### Reproduction

Given a documentation structure like:
```
docs/
  guide/
    intro/
      getting-started.md
    advanced/
      configuration.md
```

When autogenerating the sidebar, the documents don't appear in the correct nested categories. The folder hierarchy seems to be skipped or flattened incorrectly.

Example sidebar config:
```js
{
  type: 'autogenerated',
  dirName: 'guide'
}
```

### Expected behavior

The autogenerated sidebar should respect the full directory structure and create nested categories matching the folder hierarchy. Documents should be placed under their respective parent folders.

Expected sidebar structure:
- guide/
  - intro/
    - getting-started
  - advanced/
    - configuration

### System Info
- Docusaurus version: Latest
- Node version: 18.x
