# Bug Report

### Describe the bug
Menu bar visibility toggle is inverted - when I try to show the menu bar it gets hidden, and when I try to hide it, it shows up instead. The behavior is completely backwards from what's expected.

### Reproduction
1. Go to application settings
2. Toggle "Show Menu Bar" option to ON
3. Menu bar gets hidden instead of shown
4. Toggle "Show Menu Bar" option to OFF
5. Menu bar appears instead of being hidden

### Expected behavior
When the menu bar visibility setting is enabled, the menu bar should be visible. When disabled, it should be hidden. Currently it does the opposite.

### System Info
- Insomnia version: latest
- OS: Windows/Linux (any platform with auto-hide menu bar support)

This is making it really difficult to access menu options since the toggle does the opposite of what it says!
