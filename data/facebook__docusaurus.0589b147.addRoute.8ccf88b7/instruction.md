# Bug Report

### Describe the bug

Routes are not respecting the trailing slash configuration after a recent update. When I configure `trailingSlash: true` or `trailingSlash: false` in my site config, the routes generated by plugins don't follow this setting anymore.

### Reproduction

```js
// docusaurus.config.js
module.exports = {
  trailingSlash: true,
  // ... other config
}
```

When plugins add routes, they should automatically get trailing slashes appended based on the config, but it seems like the original route config is being used instead of the processed one.

For example, if a plugin adds a route `/docs/intro`, it should become `/docs/intro/` when `trailingSlash: true`, but the route remains as `/docs/intro`.

### Expected behavior

Plugin routes should respect the `trailingSlash` configuration setting. The `applyRouteTrailingSlash` function appears to be called, but the transformed route config doesn't seem to be applied correctly.

### System Info

- Docusaurus version: latest
- Node version: 18.x
