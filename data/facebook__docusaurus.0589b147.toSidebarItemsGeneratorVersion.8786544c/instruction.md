# Bug Report

### Describe the bug

When using autogenerated sidebars, the `version` object passed to the sidebar items generator function is missing the `versionName` property. Instead, it only contains `versionPath` and `contentPath`, which breaks custom sidebar generator logic that relies on accessing the version name.

### Reproduction

```js
// sidebars.js
module.exports = {
  mySidebar: [
    {
      type: 'autogenerated',
      dirName: '.',
    },
  ],
};

// Or with a custom generator function
async function myGenerator({version, docs}) {
  console.log(version.versionName); // undefined
  console.log(version.versionPath); // works
  console.log(version.contentPath); // works
  
  // Any logic depending on versionName will fail
  return docs.map(doc => ({
    type: 'doc',
    id: doc.id,
    label: `${version.versionName} - ${doc.title}` // This breaks
  }));
}
```

### Expected behavior

The `version` object should include the `versionName` property so that sidebar generators can access the human-readable version name for display purposes or conditional logic.

### System Info
- Docusaurus version: latest
- Node version: 18.x
