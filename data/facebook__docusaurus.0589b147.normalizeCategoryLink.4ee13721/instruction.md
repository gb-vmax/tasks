# Bug Report

### Describe the bug

I'm experiencing an issue with category links in the sidebar where the generated permalinks are incorrect. When using a category with a generated index, the permalink ends up being duplicated with the version path instead of including the actual slug.

### Reproduction

```js
// Sidebar configuration
{
  type: 'category',
  label: 'My Category',
  link: {
    type: 'generated-index',
    slug: '/my-custom-slug'
  },
  items: [...]
}
```

When the sidebar is processed, the generated permalink becomes something like `/docs/docs` instead of `/docs/my-custom-slug`.

### Expected behavior

The permalink should be correctly generated by combining the version path with the category slug, not by duplicating the version path. For example:
- Expected: `/docs/category/my-category` or `/docs/my-custom-slug`
- Actual: `/docs/docs`

This makes all category index pages inaccessible and breaks navigation.

### Additional context

This seems to affect categories with `generated-index` type links. Regular doc links might also be affected since there appears to be some logic changes around draft document handling as well.
