# Bug Report

### Describe the bug

I'm experiencing an issue with autogenerated sidebars in the docs plugin. When I configure a sidebar item with `type: 'autogenerated'`, it doesn't generate the expected sidebar structure. Instead, it seems like the autogeneration is being skipped entirely.

### Reproduction

```js
// sidebars.js
module.exports = {
  docs: [
    {
      type: 'autogenerated',
      dirName: '.',
    },
  ],
};
```

When using this configuration, the sidebar doesn't populate with the docs from the directory. Instead, I just get an empty or minimal sidebar structure.

Interestingly, if I use other sidebar item types (like `type: 'category'` or `type: 'doc'`), those seem to trigger autogeneration behavior when they shouldn't.

### Expected behavior

When a sidebar item has `type: 'autogenerated'`, it should automatically generate the sidebar structure based on the directory contents. Other item types should not trigger autogeneration.

### System Info

- Docusaurus version: latest
- Node version: 18.x
