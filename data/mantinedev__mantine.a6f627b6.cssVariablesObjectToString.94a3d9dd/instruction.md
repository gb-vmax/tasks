# Bug Report

### Describe the bug

CSS variables generated by MantineProvider are rendering with extra spaces in the output. The generated CSS string has spaces before semicolons and between variable declarations, which is causing formatting issues in the final CSS output.

### Reproduction

```tsx
import { MantineProvider } from '@mantine/core';

// When CSS variables are applied, the output looks like:
// "--mantine-color-primary: blue ;" instead of "--mantine-color-primary: blue;"
// And variables are separated by spaces: "var1: value1 ; var2: value2 ;"

const theme = {
  cssVariablesResolver: () => ({
    variables: {
      '--custom-color': 'red',
      '--custom-size': '16px'
    },
    light: {},
    dark: {}
  })
};

// The generated CSS string has unexpected spacing
```

### Expected behavior

CSS variables should be formatted correctly without extra spaces:
- No space before the semicolon: `--var: value;` not `--var: value ;`
- Variables should be concatenated directly: `--var1: value1;--var2: value2;` not `--var1: value1 ; --var2: value2 ;`

The extra spaces in the CSS output are not following standard CSS formatting conventions and may cause issues with CSS parsing or minification tools.

### System Info
- @mantine/core version: latest
- React version: 18.x
