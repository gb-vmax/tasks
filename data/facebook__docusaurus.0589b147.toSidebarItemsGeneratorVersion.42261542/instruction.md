# Bug Report

### Describe the bug

I'm experiencing an issue with sidebar generation where the version information passed to the sidebar items generator appears to be incorrect. When using custom sidebar item generators, the version object received doesn't contain the expected properties.

### Reproduction

```js
// In sidebars.js
module.exports = {
  mySidebar: [
    {
      type: 'autogenerated',
      dirName: '.',
    },
  ],
};

// Custom sidebar items generator
async function sidebarItemsGenerator({defaultSidebarItemsGenerator, ...args}) {
  console.log('Version info:', args.version);
  // Expected: { versionName: '1.0.0', contentPath: '/docs' }
  // Actual: { versionLabel: undefined, path: undefined }
  
  return defaultSidebarItemsGenerator(args);
}
```

### Expected behavior

The version object passed to sidebar items generators should contain `versionName` and `contentPath` properties as documented. These properties are needed to properly generate sidebar items based on version-specific information.

### System Info

- Docusaurus version: latest
- Node version: 18.x

This seems to have broken after a recent update. The generator function can't access version metadata anymore which breaks custom sidebar generation logic.
