# Bug Report

### Describe the bug

When using the sidebar items generator API, the `version` parameter passed to the generator function has the wrong property. It contains `versionLabel` instead of `versionName`, which breaks any custom sidebar generator that relies on accessing `version.versionName`.

### Reproduction

```js
// In sidebars.js or your custom generator
module.exports = {
  mySidebar: [
    {
      type: 'autogenerated',
      dirName: '.',
    },
  ],
  
  // Or using a custom generator function
  async sidebarItemsGenerator({defaultSidebarItemsGenerator, version, ...args}) {
    console.log(version.versionName); // undefined - expected to be the version name
    console.log(version.versionLabel); // Works, but should be versionName according to docs
    
    // This will fail if your code depends on versionName
    if (version.versionName === '1.0.0') {
      // custom logic
    }
    
    return defaultSidebarItemsGenerator(args);
  }
};
```

### Expected behavior

The `version` parameter should include `versionName` property as documented, allowing generators to access the version name for conditional logic or customization based on the version.

### System Info
- Docusaurus version: latest
- Node version: 18.x
