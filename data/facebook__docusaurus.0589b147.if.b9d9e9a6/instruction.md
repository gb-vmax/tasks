# Bug Report

### Describe the bug

I'm experiencing an issue with sidebar configuration where autogenerated items are not being processed correctly. When I set `type: 'autogenerated'` in my sidebar config, it seems like the autogeneration logic is being skipped entirely and the item is just passed through as-is.

### Reproduction

```js
// sidebars.js
module.exports = {
  docs: [
    {
      type: 'autogenerated',
      dirName: '.'
    }
  ]
};
```

When using the above configuration, the sidebar doesn't auto-generate items from the directory structure. Instead, it seems to treat the autogenerated item as a regular item and just returns it without processing.

### Expected behavior

The sidebar should automatically generate items based on the directory structure when `type: 'autogenerated'` is specified. The `processAutoGeneratedItem` function should be called to expand the autogenerated directive into actual sidebar items.

### System Info
- Docusaurus version: latest
- Node version: 18.x

This seems like it might be a logic error in how the sidebar processor determines which items need autogeneration. The behavior is inverted from what I'd expect.
