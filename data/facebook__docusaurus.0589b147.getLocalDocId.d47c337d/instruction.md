# Bug Report

### Describe the bug

I'm experiencing an issue with the autogenerated sidebar when using document IDs with path separators. The sidebar structure is breaking and documents are not being grouped correctly under their expected categories.

### Reproduction

When I have a document structure like:

```
docs/
  guides/
    getting-started/
      introduction.md
```

And the document ID is something like `guides/getting-started/introduction`, the sidebar generation seems to be extracting the wrong part of the path. Instead of getting the last segment of the path, it appears to be getting the first one.

### Expected behavior

The sidebar generator should correctly extract the local document ID from the full path, taking the last segment after splitting by path separators. For a document ID like `guides/getting-started/introduction`, it should extract `introduction`, not `guides`.

### System Info

- Docusaurus version: latest
- OS: Windows/Linux (happens on both)

This seems to affect how documents are organized in the autogenerated sidebar structure. The grouping logic appears to be using the wrong portion of the document path.
