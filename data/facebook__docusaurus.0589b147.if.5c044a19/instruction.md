# Bug Report

### Describe the bug

When `sidebarFilePath` is explicitly set to `undefined` in the plugin configuration, the sidebars are not being autogenerated as expected. Instead of getting the default autogenerated sidebars, the system appears to skip sidebar generation entirely.

### Reproduction

```js
// docusaurus.config.js
module.exports = {
  plugins: [
    [
      '@docusaurus/plugin-content-docs',
      {
        id: 'default',
        path: 'docs',
        sidebarPath: undefined, // Explicitly undefined to use autogenerated sidebars
      },
    ],
  ],
};
```

### Expected behavior

According to the documentation, when `sidebarPath` is `undefined`, Docusaurus should fall back to autogenerated sidebars. The sidebar should be automatically created based on the file structure in the docs directory.

### Actual behavior

The sidebars are not being generated at all when `sidebarPath` is explicitly set to `undefined`.

### System Info
- Docusaurus version: latest
- Node version: 18.x
