# Bug Report

### Describe the bug

I'm encountering an issue with the sidebar items generator in the docs plugin. When trying to access version metadata in custom sidebar generators, the properties `versionName` and `contentPath` are undefined, even though they should be available according to the documentation.

### Reproduction

```js
// In sidebars.js
module.exports = {
  mySidebar: [
    {
      type: 'autogenerated',
      dirName: '.',
    },
  ],
};

// Custom sidebar items generator
async function myGenerator({defaultSidebarItemsGenerator, version, ...args}) {
  console.log(version.versionName); // undefined
  console.log(version.contentPath); // undefined
  
  // These should contain the version name and content path
  // but they're coming through as undefined
  
  return defaultSidebarItemsGenerator(args);
}
```

### Expected behavior

The `version` object passed to sidebar items generators should contain `versionName` and `contentPath` properties as documented, allowing custom generators to access version-specific information.

### System Info
- Docusaurus version: latest
- Node version: 18.x

This is blocking our ability to customize sidebars based on version information. Any help would be appreciated!
