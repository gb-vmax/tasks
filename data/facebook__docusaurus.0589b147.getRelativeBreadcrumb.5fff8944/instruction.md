# Bug Report

### Describe the bug

When using autogenerated sidebars with nested directories, the sidebar structure is not being generated correctly. Documents that should appear in the root of the autogenerated section are not showing up, while documents in subdirectories may be appearing in unexpected locations.

### Reproduction

```
docs/
  my-section/
    intro.md
    guides/
      guide1.md
      guide2.md
```

With autogenerated sidebar config:
```js
{
  type: 'autogenerated',
  dirName: 'my-section'
}
```

### Expected behavior

The `intro.md` file should appear at the root level of the sidebar, with `guides/` as a nested category containing `guide1.md` and `guide2.md`.

### Actual behavior

The `intro.md` file is missing from the generated sidebar, or the entire directory structure is not being processed as expected. The breadcrumb logic seems to be inverted - documents at the root level of the autogenerated directory are being filtered out instead of included.

### System Info
- Docusaurus version: latest
- Node version: 18.x
