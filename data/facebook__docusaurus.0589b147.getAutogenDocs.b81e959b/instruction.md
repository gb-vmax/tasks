# Bug Report

### Describe the bug

When using autogenerated sidebars with a specific directory path, the sidebar generation is including docs from unrelated directories. For example, if I set the autogen directory to `"api"`, it's also picking up docs from directories like `"api2"` or `"apiOther"` that shouldn't be included.

### Reproduction

```js
// docusaurus.config.js or plugin config
{
  docs: {
    sidebarPath: './sidebars.js',
  }
}

// sidebars.js
module.exports = {
  mySidebar: [
    {
      type: 'autogenerated',
      dirName: 'api', // Should only include docs from 'api/' directory
    },
  ],
};
```

With the following doc structure:
```
docs/
  api/
    endpoint1.md
    endpoint2.md
  api2/
    something.md
  apiOther/
    other.md
```

### Expected behavior

The autogenerated sidebar should only include `endpoint1.md` and `endpoint2.md` from the `api/` directory.

### Actual behavior

The sidebar is also including docs from `api2/` and `apiOther/` directories, which shouldn't match the `"api"` directory name.

This seems to be a regression in how the directory matching logic works. The sidebar generation should properly check for exact directory matches or proper subdirectory paths (with trailing slashes).
