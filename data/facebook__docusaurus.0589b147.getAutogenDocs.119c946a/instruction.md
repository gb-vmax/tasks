# Bug Report

### Describe the bug

When using autogenerated sidebars with a non-root directory (e.g., `api`), all docs from the entire docs folder are being included in the sidebar instead of only the docs within the specified autogen directory. This causes the sidebar to show documents that shouldn't be there.

### Reproduction

```js
// docusaurus.config.js
module.exports = {
  presets: [
    [
      '@docusaurus/preset-classic',
      {
        docs: {
          sidebarPath: './sidebars.js',
        },
      },
    ],
  ],
};

// sidebars.js
module.exports = {
  apiSidebar: [
    {
      type: 'autogenerated',
      dirName: 'api', // Should only include docs from the 'api' folder
    },
  ],
};
```

With the following doc structure:
```
docs/
  api/
    endpoint1.md
    endpoint2.md
  guides/
    getting-started.md
    tutorial.md
```

**Current behavior:** The autogenerated sidebar includes all docs from `docs/`, including `getting-started.md` and `tutorial.md` from the `guides/` folder.

**Expected behavior:** The autogenerated sidebar should only include `endpoint1.md` and `endpoint2.md` from the `api/` folder.

This seems to have started happening recently and breaks the whole purpose of being able to scope autogenerated sidebars to specific directories.
