# Bug Report

### Describe the bug

When setting `sidebarFilePath` to `undefined` in the docs plugin configuration, the sidebars are no longer being auto-generated as expected. Instead of falling back to the default autogenerated sidebars, the plugin seems to skip sidebar generation entirely.

### Reproduction

```js
// docusaurus.config.js
module.exports = {
  plugins: [
    [
      '@docusaurus/plugin-content-docs',
      {
        id: 'default',
        path: 'docs',
        sidebarPath: undefined, // Should trigger autogenerated sidebars
      },
    ],
  ],
};
```

### Expected behavior

When `sidebarFilePath` is explicitly set to `undefined`, the plugin should fall back to autogenerated sidebars (DefaultSidebars), just like it did before. This is documented behavior where `undefined` should default to autogenerated sidebars.

### System Info

- Docusaurus version: latest
- Node version: 18.x

This used to work correctly but seems to have broken recently. The autogenerated sidebars feature is really useful for quickly getting started with docs without having to manually configure a sidebars file.
