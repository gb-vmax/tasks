# Bug Report

### Describe the bug

When `sidebarFilePath` is explicitly set to `undefined` in the docs plugin configuration, the sidebars are not being autogenerated as expected. Instead of falling back to the default autogenerated sidebars, the plugin seems to skip the autogeneration logic.

### Reproduction

```js
// docusaurus.config.js
module.exports = {
  plugins: [
    [
      '@docusaurus/plugin-content-docs',
      {
        id: 'default',
        path: 'docs',
        sidebarPath: undefined, // Explicitly set to undefined
      },
    ],
  ],
};
```

### Expected behavior

When `sidebarPath` is `undefined`, the plugin should use autogenerated sidebars (DefaultSidebars) as the fallback behavior. This is the documented default behavior when no sidebar path is specified.

### System Info
- Docusaurus version: latest
- Node version: 18.x
