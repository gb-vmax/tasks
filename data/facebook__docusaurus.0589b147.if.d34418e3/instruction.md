# Bug Report

### Describe the bug

When using the docs plugin with an explicit sidebar file path configured, the sidebars are being ignored and the default autogenerated sidebars are used instead. This seems to be a regression as it was working correctly before.

### Reproduction

```js
// docusaurus.config.js
module.exports = {
  presets: [
    [
      '@docusaurus/preset-classic',
      {
        docs: {
          sidebarPath: require.resolve('./sidebars.js'),
        },
      },
    ],
  ],
};
```

With a custom `sidebars.js` file:
```js
module.exports = {
  mySidebar: [
    'intro',
    'tutorial',
  ],
};
```

### Expected behavior

The custom sidebar configuration from `sidebars.js` should be loaded and used. Instead, the plugin is loading the default autogenerated sidebars even when `sidebarPath` is explicitly provided.

### Additional context

This affects any project that uses a custom sidebar configuration file. The sidebar structure defined in the file is completely ignored and replaced with autogenerated sidebars.
