# Bug Report

### Describe the bug

I'm having trouble with autogenerated sidebars in my docs. After updating, my sidebar configuration with `type: 'autogenerated'` is no longer working. The sidebar items that should be automatically generated are just not showing up in the navigation.

### Reproduction

```js
// sidebars.js
module.exports = {
  docs: [
    {
      type: 'autogenerated',
      dirName: 'guides',
    },
  ],
};
```

When I build my docs site, the autogenerated section doesn't appear in the sidebar. The directory exists and has markdown files, but nothing gets generated.

### Expected behavior

The sidebar should automatically generate items from the specified directory like it did in previous versions.

### System Info
- Docusaurus version: latest
- Node version: 18.x
