# Bug Report

### Describe the bug

After a recent update, the output generated by the build process has incorrect spacing/formatting for banner and outro content. The banner no longer has the expected newline separator, and the outro appears to be positioned incorrectly relative to the generated code.

### Reproduction

When building with custom banner and outro options:

```js
{
  output: {
    banner: '/* Custom Banner */',
    outro: '/* Custom Outro */'
  }
}
```

The generated output has malformed spacing - the banner is missing its trailing newline and the outro's newlines are in the wrong position (appearing before instead of after the content).

### Expected behavior

The banner should have a newline after it to separate it from the code, and the outro should have newlines after it (not before). The output should look like:

```
/* Custom Banner */
<newline>
<code content>
<newline>
<newline>
/* Custom Outro */
```

But instead it's generating something like:

```
/* Custom Banner */<code content>
<newline>
<newline>
/* Custom Outro */
```

This breaks the formatting of the generated bundles and makes them harder to read.
