# Bug Report

### Describe the bug

The autogenerated sidebar feature is not working correctly - no documents are being included in the sidebar even when there are valid docs in the specified directory. The sidebar appears empty but no warning is shown.

### Reproduction

```js
// docusaurus.config.js
module.exports = {
  presets: [
    [
      '@docusaurus/preset-classic',
      {
        docs: {
          sidebarPath: require.resolve('./sidebars.js'),
        },
      },
    ],
  ],
};

// sidebars.js
module.exports = {
  mySidebar: [
    {
      type: 'autogenerated',
      dirName: 'api', // directory with multiple .md files
    },
  ],
};
```

Directory structure:
```
docs/
  api/
    intro.md
    guide.md
    reference.md
```

### Expected behavior

The sidebar should automatically include all the markdown files from the `api` directory. Instead, the sidebar is completely empty and no documents are shown.

Interestingly, if I use a non-existent directory like `dirName: 'nonexistent'`, I also don't get any warning message which makes debugging difficult.

### System Info
- Docusaurus version: latest
- Node version: 18.x
