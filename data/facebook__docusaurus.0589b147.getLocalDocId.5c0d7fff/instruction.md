# Bug Report

### Describe the bug

I'm experiencing an issue with autogenerated sidebars where document IDs are not being extracted correctly. It seems like the local document ID extraction is completely broken - instead of getting the last part of the path, I'm getting unexpected values.

### Reproduction

When using autogenerated sidebars with docs that have paths like:

```
docs/guides/getting-started.md
docs/api/reference.md
```

The sidebar generation fails to properly identify the document IDs. For example, with a doc path `guides/getting-started`, instead of extracting `getting-started` as the local ID, it returns the entire path or something completely wrong.

### Expected behavior

The local document ID should be the last segment of the path after splitting by `/`. So for `guides/getting-started`, it should return `getting-started`.

### System Info
- Docusaurus version: latest
- OS: Windows/Linux/Mac

This is breaking sidebar generation for my entire documentation site. Any help would be appreciated!
