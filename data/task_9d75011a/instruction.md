I'm setting up a local binary artifact repository manager and need help initializing the environment from a configuration file. The config file already exists at `/home/user/artifact-manager/repos.conf` and defines the repositories I want to manage.

Please do the following:

**1. Create the repository directory structure**

For each repository listed in `/home/user/artifact-manager/repos.conf`, create a subdirectory under `/home/user/artifact-manager/storage/`. Each line in `repos.conf` has the format:

```
<repo_name>:<repo_type>:<retention_days>
```

For example, a line `libs-release:maven:90` means a repo named `libs-release` of type `maven` with 90-day retention. Create one directory per repo: `/home/user/artifact-manager/storage/<repo_name>/`.

**2. Generate the manifest file**

Create a manifest file at `/home/user/artifact-manager/storage/MANIFEST` with the following exact format:

```
# Artifact Repository Manifest
# Generated by: artifact-manager
repos: <total_count>

[<repo_name>]
type=<repo_type>
retention_days=<retention_days>
path=storage/<repo_name>
```

One block per repository (in the same order as `repos.conf`), each block separated by a blank line. The header block (the two comment lines and `repos:` line) should also be followed by a blank line before the first repo block.

**3. Set permissions**

Each repository directory under `/home/user/artifact-manager/storage/` should have permissions `750` (rwxr-x---). The `MANIFEST` file should have permissions `640` (rw-r-----).

For example, if `repos.conf` contained exactly two lines:
```
libs-release:maven:90
docker-local:docker:30
```

Then `MANIFEST` would contain:
```
# Artifact Repository Manifest
# Generated by: artifact-manager
repos: 2

[libs-release]
type=maven
retention_days=90
path=storage/libs-release

[docker-local]
type=docker
retention_days=30
path=storage/docker-local
```

And the directories `/home/user/artifact-manager/storage/libs-release/` and `/home/user/artifact-manager/storage/docker-local/` would both exist with permissions `750`.
