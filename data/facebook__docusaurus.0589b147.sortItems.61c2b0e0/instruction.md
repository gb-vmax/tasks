# Bug Report

### Describe the bug

When using autogenerated sidebars with nested categories, the sorting behavior seems to be broken. The sidebar items within categories are not being sorted according to their position/source metadata.

### Reproduction

Create a docs structure with nested categories and position frontmatter:

```
docs/
  category1/
    _category_.json (position: 1)
    doc1.md (position: 2)
    doc2.md (position: 1)
    subcategory/
      _category_.json (position: 2)
      doc3.md (position: 2)
      doc4.md (position: 1)
```

With autogenerated sidebars enabled, the items inside the categories appear in the wrong order - they're not respecting the position values specified in the frontmatter.

### Expected behavior

All sidebar items should be sorted by their position metadata, including items nested within categories. The sorting should be applied recursively to all levels of the sidebar hierarchy.

### System Info
- Docusaurus version: latest
- Node version: 18.x
