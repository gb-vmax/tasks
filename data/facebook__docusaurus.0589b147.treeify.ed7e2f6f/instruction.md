# Bug Report

### Describe the bug

I'm experiencing an issue with the autogenerated sidebar structure where nested directories are not being created correctly. When I have documentation files in subdirectories, the sidebar generation seems to be skipping or flattening the directory structure instead of properly nesting the items.

### Reproduction

Here's my directory structure:
```
docs/
  autogen/
    guide/
      getting-started.md
      advanced/
        configuration.md
```

When using the autogenerated sidebar feature, the nested `advanced` folder under `guide` doesn't appear in the sidebar hierarchy as expected. The files seem to be placed at the wrong level or not organized into their proper parent categories.

### Expected behavior

The sidebar should reflect the actual directory structure with proper nesting:
- guide/
  - getting-started
  - advanced/
    - configuration

Instead, the structure appears flattened or the nested directories are missing from the generated sidebar.

### System Info
- Docusaurus version: latest
- Node version: 18.x

This might be related to how the breadcrumb paths are being calculated for nested directories. The issue only appears when there are multiple levels of nesting within the autogenerated directory.
