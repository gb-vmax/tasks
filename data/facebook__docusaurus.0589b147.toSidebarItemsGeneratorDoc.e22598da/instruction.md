# Bug Report

### Describe the bug

When using autogenerated sidebars with the docs plugin, the `sidebarPosition` frontmatter field is not being passed to the sidebar items generator function. This means custom sidebar generators can't access the `sidebarPosition` property to control item ordering.

### Reproduction

```js
// In a custom sidebar items generator
function mySidebarItemsGenerator({docs}) {
  docs.forEach(doc => {
    console.log(doc.sidebarPosition); // undefined
  });
}
```

With a doc file containing:
```md
---
sidebarPosition: 5
---

# My Doc
```

### Expected behavior

The `sidebarPosition` frontmatter property should be available on doc objects passed to sidebar items generator functions, allowing custom generators to respect the position specified in frontmatter.

### System Info
- Docusaurus version: latest
- Node version: 18.x
