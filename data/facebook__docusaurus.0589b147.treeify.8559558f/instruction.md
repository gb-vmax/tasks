# Bug Report

### Describe the bug

I'm experiencing an issue with autogenerated sidebars where the directory structure isn't being created properly. When I have docs organized in subdirectories, they're not appearing in the sidebar at all or appearing in the wrong location.

### Reproduction

Here's my docs structure:
```
docs/
  intro.md
  guides/
    getting-started.md
    advanced/
      configuration.md
```

When I use autogenerated sidebars:
```js
{
  type: 'autogenerated',
  dirName: '.'
}
```

The nested docs under `guides/advanced/` don't show up in the sidebar. The sidebar generation seems to fail silently for documents in subdirectories.

### Expected behavior

All documents should appear in the sidebar with the proper nested structure:
- intro
- guides/
  - getting-started
  - advanced/
    - configuration

### System Info
- Docusaurus version: latest
- Node version: 18.x

This was working fine before, not sure what changed. Any help would be appreciated!
