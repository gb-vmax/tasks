# Bug Report

### Describe the bug

Autogenerated sidebars are not being sorted correctly when using the `position` frontmatter field. The sidebar items appear in an unexpected order, and the position values seem to be ignored during sorting.

### Reproduction

1. Create multiple docs with position frontmatter:

```md
---
position: 3
---
# Doc A
```

```md
---
position: 1
---
# Doc B
```

```md
---
position: 2
---
# Doc C
```

2. Use autogenerated sidebar configuration
3. Build the site

### Expected behavior

The sidebar should display items in the order: Doc B (position 1), Doc C (position 2), Doc A (position 3).

### Actual behavior

The items appear in a different order, seemingly ignoring the position values. The sorting doesn't respect the position frontmatter field.

### System Info

- Docusaurus version: 3.x
- Node version: 18.x

This seems to have started recently. The position field used to work correctly for ordering sidebar items.
