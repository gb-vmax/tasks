# Bug Report

### Describe the bug

When using autogenerated sidebars with a directory that has a prefix matching another directory name, docs from the wrong directory are being included in the sidebar. For example, if I have directories `api` and `api2`, docs from `api2` are incorrectly appearing in the autogenerated sidebar for `api`.

### Reproduction

Directory structure:
```
docs/
  api/
    doc1.md
  api2/
    doc2.md
```

Sidebar config:
```js
{
  type: 'autogenerated',
  dirName: 'api'
}
```

### Expected behavior

The autogenerated sidebar for `api` should only include `doc1.md` from the `api` directory. Currently, it's also including `doc2.md` from the `api2` directory because `"api2".startsWith("api")` returns true.

### System Info
- Docusaurus version: latest
- Node version: 18.x
