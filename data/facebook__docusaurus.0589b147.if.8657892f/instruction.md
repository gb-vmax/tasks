# Bug Report

### Describe the bug

I'm experiencing an issue with sidebar generation where autogenerated sidebar items are not being processed correctly. When I configure a sidebar with `type: 'autogenerated'`, the sidebar doesn't render as expected and the autogenerated content is missing.

### Reproduction

```js
// sidebars.js
module.exports = {
  docs: [
    {
      type: 'autogenerated',
      dirName: '.',
    },
  ],
};
```

After setting up an autogenerated sidebar like above, the sidebar appears empty or doesn't include the expected auto-generated items from the docs directory.

### Expected behavior

The sidebar should automatically generate items based on the directory structure when using `type: 'autogenerated'`. All markdown files in the specified directory should be included in the sidebar.

### System Info
- Docusaurus version: latest
- Node version: 18.x
