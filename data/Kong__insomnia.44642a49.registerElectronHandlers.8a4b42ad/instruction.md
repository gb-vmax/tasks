# Bug Report

### Describe the bug

The menu bar visibility toggle is not working correctly. When I try to hide the menu bar, it remains visible, and when I try to show it, it gets hidden instead. The behavior seems to be completely inverted from what's expected.

### Reproduction

1. Go to application settings
2. Toggle "Show Menu Bar" to OFF
3. Menu bar remains visible instead of hiding
4. Toggle "Show Menu Bar" to ON
5. Menu bar hides instead of showing

### Expected behavior

When the "Show Menu Bar" option is enabled, the menu bar should be visible. When disabled, the menu bar should be hidden. The current behavior is the opposite of what it should be.

### System Info
- Insomnia version: latest
- OS: Windows/Linux (auto-hide menu bar feature)
