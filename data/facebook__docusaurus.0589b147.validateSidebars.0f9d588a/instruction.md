# Bug Report

### Describe the bug

I'm getting a runtime error when trying to use sidebars in my Docusaurus project. The error says `sidebarId.forEach is not a function`, which suggests something is trying to iterate over a string instead of an array.

### Reproduction

```js
// sidebars.js
module.exports = {
  tutorialSidebar: [
    {
      type: 'category',
      label: 'Tutorial',
      items: ['hello', 'tutorial-basics/create-a-document'],
    },
  ],
  apiSidebar: [
    {
      type: 'autogenerated',
      dirName: 'api',
    },
  ],
};
```

When the site builds or runs in dev mode, it crashes with:

```
TypeError: sidebarId.forEach is not a function
```

This happens during sidebar validation. It seems like the validation logic is trying to call `forEach` on the sidebar ID (which is a string like "tutorialSidebar") instead of the actual sidebar items array.

### Expected behavior

The sidebars should validate correctly and the site should build/run without errors.

### System Info
- Docusaurus version: latest
- Node version: 18.x
