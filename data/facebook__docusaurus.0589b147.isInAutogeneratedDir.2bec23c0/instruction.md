# Bug Report

### Describe the bug

I'm experiencing an issue with autogenerated sidebars where documents are being incorrectly included or excluded from the generated sidebar. It seems like the logic for determining whether a doc belongs in an autogenerated directory isn't working as expected.

### Reproduction

Given a docs structure like:
```
docs/
  api/
    intro.md
  api-reference/
    guide.md
```

When using autogenerated sidebars with `autogenDir: 'api'`, documents from `api-reference/` are being included in the sidebar even though they shouldn't be (since "api-reference" shouldn't match "api").

Similarly, in some configurations, docs that should be included are being excluded.

### Expected behavior

Only documents that are:
1. Directly in the `api/` directory, OR
2. In subdirectories of `api/` (like `api/endpoints/`)

should be included in the autogenerated sidebar. Documents in `api-reference/` or other directories that just happen to start with "api" should NOT be included.

### System Info
- Docusaurus version: latest
- Node version: 18.x
