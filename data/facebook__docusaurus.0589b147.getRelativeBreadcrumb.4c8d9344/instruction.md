# Bug Report

### Describe the bug

I'm experiencing an issue with autogenerated sidebars where the directory structure isn't being recognized correctly. When I set up sidebar autogeneration with a specific directory, the nested folder hierarchy is not being reflected properly in the generated sidebar.

### Reproduction

Here's my setup:

```js
// sidebars.js
module.exports = {
  docs: [
    {
      type: 'autogenerated',
      dirName: 'guides'
    }
  ]
};
```

With the following directory structure:
```
docs/
  guides/
    getting-started/
      intro.md
      setup.md
    advanced/
      config.md
```

### Expected behavior

The sidebar should display the nested structure with `getting-started` and `advanced` as categories containing their respective docs.

### Actual behavior

The sidebar structure appears flattened or incorrectly organized. Documents that should be nested under subdirectories are not being placed in the right categories.

### System Info

- Docusaurus version: latest
- Node version: 18.x

This seems to have started happening recently. The autogenerated sidebar was working fine before with the same directory structure.
